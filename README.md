# 提出期限管理アプリ（仮）

提出物・課題・各種タスクの「期限」を中心に管理するWebアプリです。  
一般的なToDo管理だけでなく、「◯月上旬／中旬／下旬」といった曖昧な締切にも対応し、現実的な提出管理をしやすくすることを目的としています。

## ✨ このアプリの特徴

- 「上旬 / 中旬 / 下旬」での期限管理に対応
- 提出物・課題管理に特化した設計
- 提出先やメモを記録可能
- 表紙画像を設定して視覚的に管理
- 完了 / 未完了 / アーカイブで状態管理

---

## 🛠 主な機能

- タスクの追加・削除
- 期限管理
  - 日付指定
  - おおまか指定（上旬 / 中旬 / 下旬）
- タスクの編集
  - タスク名
  - 期限の再設定
  - 提出先の編集
  - メモの追加・編集
- 完了 / 未完了の切り替え
- アーカイブ機能
- 表紙画像の設定（IndexedDB使用）

---

## 📖 使い方

1. 「＋ タスクを追加」からタスク名と期限を入力
2. 必要に応じて提出先・メモ・表紙画像を設定
3. タスクをタップすると詳細を表示
4. 「編集」ボタンから内容を更新可能
5. 完了したタスクは完了ボタンで管理

## 💾 データ保存について

- タスク情報は LocalStorage に保存されます
- 表紙画像は IndexedDB に保存されます
- ブラウザのデータ削除やキャッシュクリアにより、データが消える場合があります

---

## 🧠 開発の背景

提出物やタスク管理では、「◯日までに必ず」という厳密な期限だけでなく、  
「◯月中旬くらいまでに」といった曖昧な締切が多く存在します。

既存のタスク管理ツールではこうした曖昧さを扱いづらいと感じたため、  
現実的な期限感覚にフィットする管理アプリとして開発しました。
