# 提出期限管理アプリ（仮）

提出物・タスクの「期限」を中心に管理するシンプルなWebアプリです。
日付指定だけでなく「◯月上旬／中旬／下旬」といった
おおまかな期限管理にも対応しています。

## 主な機能

- タスクの追加・削除
- 期限管理
  - 日付指定
  - おおまか指定（上旬 / 中旬 / 下旬）
- タスクの編集
  - タスク名
  - 期限の再設定
  - 提出先の編集
  - メモの追加（編集時のみ）
- 完了 / 未完了の切り替え
- アーカイブ機能
- 表紙画像の設定（IndexedDB使用）

## 使い方

1. 「＋ タスクを追加」からタスク名と期限を入力
2. 必要に応じて提出先や表紙画像を設定
3. タスクをタップすると詳細を表示
4. 「編集」ボタンから内容を更新可能
5. 完了したタスクは完了ボタンで管理

## 技術スタック

- HTML / CSS / JavaScript（Vanilla）
- LocalStorage（タスクデータ保存）
- IndexedDB（画像データ保存）
- Service Worker（PWA対応）

## 開発の背景

提出物やタスク管理では、
「◯日までに必ず」ではなく
「◯月中旬くらいまでに」という曖昧な期限が多く存在します。

本アプリは、そうした現実的な期限感覚を
無理なく管理できることを目的として開発しました。
